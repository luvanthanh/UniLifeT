# UniLifeT Customer

React customer app built with Vite. Room, motel, university, image, profile, favorite, and rental data is loaded from the UniLifeT backend API.

## Run locally

1. Start the backend at `http://localhost:8080`.
2. From this folder, run `npm install`.
3. Run `npm run dev` and open `http://127.0.0.1:5501`.

Set `VITE_API_URL` in a `.env` file to use a different backend URL. The default is `http://localhost:8080`.
